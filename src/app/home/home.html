Demonstrating React State & Memoization equivalents in Angular

1. State (React: useState → Angular: signal)

In React, you use const [count, setCount] = useState(0). In modern Angular, we use Signals. A signal is a reactive value that notifies Angular when it changes.

Current Count (State) {{ count() }}

2. Memoization (React: useMemo → Angular: computed)

In React, you use const doubleCount = useMemo(() => count * 2, [count]) to cache expensive calculations. In Angular, we use computed signals. They are automatically cached, read-only, and only re-calculate when their dependency signals change.

Double Count (Memoized) {{ doubleCount() }}

Notice how this value updates instantly and automatically when the count changes, without manually calling any update functions.
