Demonstrating React Refs & Effects equivalents in Angular

1. Refs (React: useRef → Angular: viewChild)

In React, you use const inputRef = useRef(null) to access DOM elements directly. In Angular, you mark the element in HTML with a template reference variable #myInput and grab it in TypeScript using viewChild('myInput').

2. Effects (React: useEffect → Angular: effect)

In React, you run side-effects with useEffect(() => { ... }, [dep]). In Angular, you use effect() inside the constructor. Angular automatically tracks which signals are read inside the effect and re-runs it whenever those signals change.
